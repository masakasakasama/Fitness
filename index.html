東上野店の機材構成にする

機材リストをチョコザップ東上野店の実機材（10種）に置き換えます。過去の記録は残ります。

☁️ GitHub自動保存

Personal Access Token を設定すると、記録が自動で masakasakasama/Fitness リポジトリに保存され、別の端末からも同じデータを使えるようになります。

トークンの作り方
  1. Fine-grained PAT 作成画面 を開く
  2. Repository access → Only select repositories → Fitness を選択
  3. Repository permissions → Contents → Read and write
  4. Generate token して github_pat_… をコピー、下に貼り付け

⚠️ トークンはこの端末のブラウザにのみ保存されます。リポジトリが Public のままだと記録は誰でも閲覧可能です。非公開にしたい場合は GitHub の Settings → General → Change visibility → Private に変更してください。
