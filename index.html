GitHub自動保存

Personal Access Token を設定すると、記録が自動で masakasakasama/Fitness に保存されます。複数端末で同じデータを共有できます。

トークンの作り方
  1. Fine-grained PAT 作成画面 を開く
  2. Repository access → Only select repositories → Fitness
  3. Repository permissions → Contents → Read and write
  4. Generate token → 下に貼り付け

トークンはこの端末にのみ保存されます。Public リポジトリだと記録は誰でも閲覧可能です（Settings → Change visibility で Private に）。
